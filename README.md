# Surakshaka Poojari — AI Engineer Portfolio

A responsive, futuristic single-page portfolio built with HTML, CSS and vanilla JavaScript. Designed for GitHub Pages.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public GitHub repository (for example `surakshaka-portfolio`).
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your public Pages URL.

## Before publishing
- Replace the LinkedIn placeholder URL with your actual profile URL.
- Add your GitHub profile link if you want it displayed.
- Review the project descriptions and keep only work you are comfortable sharing publicly.
- The portfolio deliberately avoids client names, confidential details and unverified performance metrics.
- The terminal panel and particle animation are visual design elements; there is no live AI chatbot backend connected.
